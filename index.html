Чтение стадий ретинопатии недоношенных

105 публичных кадров (ROP-VL, CC BY 4.0), по одному на ребёнка, в случайном порядке. Порядок не отражает стадию. Отвечайте по своему чтению — ответы модели здесь не показываются.

Что заполнять на каждом кадре:

  • Стадия РН: нет / 1 / 2 / 3 / 4 / 5 / не уверен(а)
  • A-ROP: нет / да / не уверен(а) — это отдельный вопрос, не стадия
  • Зона: I / II / III / не вижу
  • Плюс-болезнь: норма / пре-плюс / плюс / не уверен(а)
  • Качество кадра: хорошее / среднее / плохое (плохое — если стадию по нему не поставить)

Можно пропустить кадр и вернуться: ответы сохраняются в браузере автоматически. В конце — кнопка «Выгрузить ответы»: скачается JSON, его и пришлите.
